# Blossom Planner 🌸

A beautiful, feature-rich student task management app designed to help you stay organized and accountable.

## Features

- **Smart Task Management** – Create tasks with priority, due dates, and progress tracking
- **Intelligent Dashboard** – Get an overview of urgent tasks, completion stats, and personalized suggestions
- **Live Countdowns** – See exactly how much time you have left for each task
- **Social Accountability** – Share public tasks with friends and track their progress
- **Privacy Controls** – Choose which tasks are public or private
- **Theme Customization** – Pick from 4 beautiful color themes
- **Real-time Notifications** – Stay updated with important events

## How to Use

1. Sign up or log in to your account
2. Head to "My Tasks" to create your first task
3. Monitor progress on your Dashboard
4. Add friends to share accountability
5. Customize your theme and preferences in Settings

## Technical Stack

- Frontend: HTML5, CSS3, JavaScript (ES6+), TypeScript
- Storage: localStorage-backed JSON database
- Architecture: Client-side web app with modular components
